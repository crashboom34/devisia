## 1️⃣ CRÉER UN PROJET SANS DEVIS

### Pourquoi ?
Vous pouvez maintenant créer un projet et ajouter des informations progressivement, **sans être obligé de générer des devis immédiatement**.

### Comment faire ?

#### Sur le Dashboard
Vous avez maintenant **2 boutons** :

1. **"Créer un Projet"** (nouveau)
   - Pour créer un projet simple
   - Ajouter infos client, adresse, photos
   - Générer devis plus tard

2. **"Projet + Devis"** (comme avant)
   - Crée projet + génère 3 devis immédiatement
   - Workflow rapide habituel

### Étapes pour créer un projet simple

```
1. Dashboard → Cliquer "Créer un Projet"

2. Remplir le formulaire :
   ✅ Titre du projet *
   📝 Description
   👤 Nom du client
   🏠 Adresse du chantier
   🔨 Type de travaux
   📋 Notes / Remarques

3. Cliquer "Enregistrer le Projet"

4. → Vous êtes redirigé vers la page du projet
```

### Que faire après ?

Une fois le projet créé, vous pouvez :
- ✅ Ajouter des pièces et des photos
- ✅ Compléter les informations
- ✅ Générer des devis quand vous êtes prêt

## 2️⃣ AJOUTER DES PHOTOS PAR PIÈCE

### Pourquoi ?
Documentez visuellement votre chantier avec des photos organisées par pièce, avec dimensions et commentaires.

### Où trouver cette fonction ?

```
Page Projet → Onglet "📷 Photos"
```

### Comment ajouter une pièce ?

```
1. Cliquer "Ajouter une pièce"

2. Remplir :
   - Nom * : Ex: "Salon", "Chambre 1", "Façade sud"
   - Description : Détails sur la pièce (optionnel)

3. Cliquer "Ajouter"
```

### Comment ajouter une photo ?

```
1. Sur la pièce → Cliquer "Ajouter photo"

2. Choisir la photo :
   📱 Sur mobile : Prendre photo ou choisir dans galerie
   💻 Sur ordinateur : Choisir fichier

3. Remplir (optionnel) :
   📐 Dimensions : Ex: "3,50m x 4,20m, HSP 2,50m"
   💬 Commentaire : Ex: "Mur fissuré côté fenêtre"

4. Cliquer "Ajouter"
```

### Exemple d'utilisation

**Projet : Rénovation Maison Combaillaux**

**Pièce : Salon**
- Photo 1 : Vue générale
  - Dimensions : "4,50m x 5,20m, HSP 2,60m"
  - Commentaire : "Mur à reprendre"
- Photo 2 : Fenêtre
  - Dimensions : "Fenêtre 1,40m x 1,80m"
  - Commentaire : "Remplacer double vitrage"

**Pièce : Chambre 1**
- Photo 1 : Parquet abîmé
  - Dimensions : "3,20m x 3,80m"
  - Commentaire : "Parquet à poncer et vitrifier"

### Gérer les photos

- ✅ Voir toutes les photos d'une pièce
- ✅ Supprimer une photo
- ✅ Supprimer une pièce (supprime aussi ses photos)

## 3️⃣ 10 NOUVEAUX TEMPLATES BTP

### Pourquoi ?
Des templates professionnels prêts à l'emploi pour accélérer la création de devis.

### Liste des Templates Disponibles

| # | Nom du Template | Catégorie |
|---|----------------|-----------|
| 1 | Travaux de second œuvre intérieur | Second œuvre |
| 2 | Extension de maison | Gros œuvre + Second œuvre |
| 3 | Rénovation complète d'une pièce | Rénovation |
| 4 | Construction maison individuelle TCE | Maison neuve |
| 5 | Aménagement de combles | Rénovation / Transformation |
| 6 | Transformation garage en pièce habitable | Rénovation / Transformation |
| 7 | Surélévation de maison | Gros œuvre + Second œuvre |
| 8 | Aménagement de local commercial | Aménagement intérieur / Tertiaire |
| 9 | VRD et aménagements extérieurs | Extérieur / VRD |
| 10 | Piscine, poolhouse et terrasse | Extérieur / Loisirs |

### Contenu des Templates

Chaque template contient :
- 📋 **Lots de travaux** organisés logiquement
- 🔨 **Postes détaillés** pour chaque lot
- 💰 **3 gammes de prix** :
  - **Entrée** : Solution économique
  - **Standard** : Qualité professionnelle
  - **Premium** : Haut de gamme

### Exemple : Template "Second œuvre intérieur"

**Lots inclus :**

1. **Préparation et protections**
   - Protection des zones

2. **Cloisons et plâtrerie**
   - Création/modification cloisons (BA13)
   - Reprise murs et plafonds

3. **Électricité intérieure**
   - Création/modification points électriques

4. **Revêtements de sols**
   - Pose parquet, carrelage, stratifié

5. **Peintures et finitions**
   - Peinture murs et plafonds

**Chaque poste a 3 descriptions :**
- Gamme Entrée : "BA13 simple peau sur ossature standard"
- Gamme Standard : "BA13 sur ossature renforcée avec isolant phonique"
- Gamme Premium : "Cloisons acoustiques avec isolant hautes performances"

### Comment utiliser les templates ?

Les templates sont actuellement en base de données et seront utilisables dans les prochaines versions pour :
- ✅ Pré-remplir rapidement un devis
- ✅ Personnaliser les lots selon votre projet
- ✅ Assurer des devis professionnels et complets

## 📱 UTILISATION MOBILE

### Prise de Photos

**Sur iOS / Android :**
```
1. Onglet Photos → Ajouter photo
2. Le navigateur propose :
   - 📸 "Prendre une photo"
   - 🖼️ "Choisir photo existante"
3. Sélectionner option
4. Photo uploadée automatiquement
```

### Conseils Mobile

✅ **Testez votre connexion**
- Upload photos nécessite connexion stable

✅ **Orientation**
- Photos paysage/portrait OK
- Rotation automatique

✅ **Taille**
- Compression automatique
- Limite : 5MB par photo (ajustable)

## ⚠️ CONFIGURATION REQUISE

### Pour les Photos

Le bucket Supabase `project-photos` doit être configuré :

```
1. Dashboard Supabase → Storage
2. Créer bucket "project-photos"
3. Configurer :
   - Public: Oui (ou RLS)
   - Taille max: 5MB
   - Types: image/*
```

## ❓ FAQ

### Q : Puis-je encore créer projet + devis en une fois ?
**R :** Oui ! Le bouton "Projet + Devis" fonctionne exactement comme avant.

### Q : Les photos sont-elles obligatoires ?
**R :** Non, c'est optionnel. Vous pouvez créer des projets sans photos.

### Q : Puis-je modifier les informations client plus tard ?
**R :** Oui, via le bouton "Modifier" sur la page projet.

### Q : Les dimensions doivent-elles être exactes ?
**R :** Non, c'est du texte libre. Vous pouvez écrire ce que vous voulez (ex: "environ 4m x 5m").

### Q : Combien de photos par pièce ?
**R :** Illimité (dans la limite raisonnable du stockage).

### Q : Les templates sont-ils modifiables ?
**R :** Les administrateurs peuvent les modifier. Ils serviront de base pour futures fonctionnalités.
